# AI-automator

An open-source project that learns repetitive computer tasks by watching how users perform them.

The idea is simple: a user demonstrates a workflow on their screen, and the assistant takes time to understand the steps, recognize patterns, and identify which details change from one run to the next. It can then suggest an automation for the user to review, test, and improve.

The goal is to make automation accessible without requiring users to write scripts or manually configure every step. By keeping the project open source, we can build a transparent, community-driven tool that gives people more control over how their workflows are learned and automated.
